# World News — 26 November 2026

A single 1024×1024 infographic that summarizes the world news of Thursday
26 November 2026: six top stories plus two briefs, each with a headline, a
one-line summary and a source line.

The image is pre-rendered and committed as `news-2026-11-26.png`. `main.py`
is a standard-library-only program that copies that image to the output
directory as `entry.png`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png`. If `MAKEFUN_OUTPUT_DIR` is unset it defaults to
`/output`.
